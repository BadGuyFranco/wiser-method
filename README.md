# The WISER Method

**Mastering perpetual innovation using [AI First Principles](https://aifirstprinciples.org)**

WISER enables teams to innovate continuously without operational disruption. Five canons, 26 plays, and a practitioner toolkit for teams where stagnation is more dangerous than change.

## What's in This Repository

**The Method** (`method/WISER Method.md`). The complete WISER methodology: canons, plays, positions, playbook structure. This is the authoritative source.

**Practitioner Templates** (`templates/`). 35 templates organized by canon. Description specs (format-neutral blueprints), HTML sources for PDF reference cards, and a CSS design system. Use these to build WISER tooling in any platform.

## Quick Start

1. Read `method/WISER Method.md` to understand the methodology
2. Browse `templates/` for the practitioner templates organized by canon
3. Use the description specs (`description.md` files) to build templates in your tool of choice
4. Use the HTML/CSS files to generate PDF reference cards

Ready-to-use Notion and Google Sheets versions are available at [wisermethod.com/templates](https://wisermethod.com/templates).

## The Five Canons

| Canon | Purpose |
|-------|---------|
| **Witness** | See what's actually happening. Map friction, observe workflows, document reality. |
| **Interrogate** | Challenge assumptions. Rapid experiments before committing to months of development. |
| **Solve** | Deliver a single working solution that earns organizational trust. |
| **Expand** | Scale reach without scaling risk. Modularize success for related problems. |
| **Refine** | Grow autonomy through evidence. Monitor drift, graduate trust. |
